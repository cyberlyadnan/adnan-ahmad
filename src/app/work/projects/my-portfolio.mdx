## Overview

**The Seerah Library** is a digital platform designed to help users discover, read, and reflect on the life of Prophet Muhammad ﷺ through a curated collection of books. The platform features detailed metadata, AI-powered exploration tools, and a clean, responsive user interface. The goal was to create a scalable, SEO-friendly, and user-centric web experience that bridges traditional Islamic scholarship with modern technology.

## Key Features

- **Book Metadata Management**: Structured each book with comprehensive metadata including author details, language, genre, ratings, tags, and publication dates using Firebase Firestore.
- **Server-Side Rendering for SEO**: Implemented SSR in Next.js to load content directly from Firestore for better indexing and performance.
- **Pagination and Explore Grid**: Designed a dynamic explore page that initially loads 6 books with pagination-ready architecture for scalability.
- **AI-Powered Book Chat (Planned)**: Integrated plans for AI-based chat interface to ask questions and get answers based on book content.
- **Author Profiles**: Linked each book with an author profile, allowing users to discover other works by the same author and understand the scholarly background.
- **Authentication**: Integrated secure login with Firebase Authentication for bookmarking, reviewing, and personal interaction with the content.

## Technologies Used

- **Next.js 14 (App Router)**: For server-side rendering and dynamic routing.
- **TailwindCSS**: For fast, utility-first UI development.
- **Firebase (Firestore & Auth)**: For backend data storage, authentication, and real-time updates.
- **TypeScript**: For robust type safety across components and APIs.
- **Shadcn/UI & Lucide Icons**: For polished UI components and iconography.
- **Vercel**: For deployment and edge performance.

## Challenges and Learnings

One of the core challenges was building a flexible yet scalable data structure in Firestore for books, authors, and reviews. Ensuring strong typing with `SeerahBook` interfaces helped catch issues early. Another key learning was balancing dynamic UI with server-rendered SEO benefits—especially when fetching and displaying paginated book data.

## Outcome

The Seerah Library serves as a modern gateway to learning about the Seerah through a beautiful, performant, and accessible platform. It has laid the foundation for deeper features such as AI chatbots, review systems, and donation-based book sponsorship. This project reflects a strong blend of frontend engineering, backend integration, and Islamic values in tech.

## Overview

**StreamMaster** is a powerful YouTube clone built with a focus on performance, responsiveness, and scalability. It provides a seamless video browsing and playback experience with advanced features like live video sections, Redux-based state management, and optimized data loading.

## Key Features

- ⚡ **Performance Optimization**: Implemented lazy loading, debouncing on search inputs, and API response caching to reduce load time by over 40%.
- 🎥 **Video Playback and Navigation**: Smooth and uninterrupted video streaming with efficient routing and UI transitions.
- 📡 **Live Section with API Polling**: Dynamically fetched live content using polling logic to simulate real-time updates.
- 📦 **State Management with Redux**: Centralized and scalable state architecture ensuring smooth video and UI interactions.
- 📱 **Fully Responsive UI**: Built with **Tailwind CSS**, the interface adapts beautifully across mobile, tablet, and desktop screens.
- 🚀 **Deployment with Firebase**: Hosted on Google Firebase to ensure high uptime, fast delivery, and easy scalability.

## Technologies Used

- **React + Redux** – Component-driven UI with robust state control
- **Tailwind CSS** – Utility-first responsive styling
- **Firebase Hosting** – Reliable and fast deployment
- **YouTube Data API (v3)** – For dynamic content retrieval
- **Axios & Lodash** – For efficient HTTP requests and performance enhancements
- **Lazy Loading & Debouncing** – To enhance speed and user interaction

## Challenges and Learnings

Working with YouTube APIs brought challenges in data structuring and rate limiting. I learned to optimize API usage through debouncing and implemented custom caching logic. Redux integration also helped streamline state sharing across components while maintaining performance under heavy UI activity.

## Outcome

**StreamMaster** is a production-grade YouTube clone that highlights my ability to build scalable, performant, and user-focused web apps. It's a perfect blend of frontend performance, real-world API integration, and modern UI/UX principles.

## Overview

**VSell** is a modern food ordering platform built as an internship assignment to showcase my ability to build real-world, user-centric interfaces. The application allows users to search for food items in real time, add them to a cart, mark items as favorites, and manage state efficiently with performance in mind. The UI was developed using best frontend practices and optimized for responsiveness across all devices.

## Key Features

- 🔍 **Real-Time Live Search**: Users can instantly filter items on the Explore page using input keywords with smooth feedback.
- 🛒 **Shop Page**: Displays food items dynamically, allowing users to browse, favorite, and add them to a cart.
- ❤️ **Favorites & Cart**: Items are saved using `localStorage`, ensuring persistence even after page reloads.
- ⚡ **Performance Optimizations**: Lazy loading, minimal re-renders, and efficient data flow enhance app speed.
- 💬 **User Feedback & Error Handling**: Graceful fallbacks and messaging for empty states, errors, or no matches.
- 🎯 **Best Practices**: Utilized destructuring, optional chaining, and clean modular code throughout the app.

## Technologies Used

- **Next.js 14 (App Router)** – For routing and scalable project structure.
- **React** – Component-based UI structure and hooks-based state management.
- **Tailwind CSS** – Rapid styling with utility-first classes.
- **Local Storage** – Persistent cart and favorites functionality.
- **TypeScript-Ready Architecture** – Clean structure and safe development practices.

## Challenges and Learnings

One of the biggest takeaways from this project was managing real-time UI updates with efficient re-rendering. I learned to keep components performant while also handling edge cases like empty states or invalid actions. Designing the favorites and cart logic with `localStorage` added persistence and realism to the app’s functionality.

## Outcome

VSell demonstrates my ability to create highly responsive, user-focused applications from scratch while adhering to best frontend practices. The project showcases both UI/UX finesse and technical strength—making it a valuable addition to my portfolio.

## Overview

**CinemaFlixGemini** is a smart Netflix clone that integrates **Gemini AI** for intelligent movie discovery and recommendations. Built with Firebase Auth, responsive UI, and dynamic routing, the platform mimics the feel of a modern OTT service while offering a tailored user experience through AI.

## Key Features

- 🤖 **Smart Search with Gemini AI**: Delivered AI-powered movie suggestions and contextual search, increasing user engagement by 30%.
- 🔐 **Secure Authentication**: Integrated **Firebase Auth** with Google Sign-In to manage users and ensure secure access.
- 🛡 **Protected Routes**: Implemented conditional routing to gate premium content for authenticated users, enhancing retention and value.
- 📱 **Responsive UI**: Designed using **Tailwind CSS**, the app maintains consistent UX across mobile, tablet, and desktop.
- ⚙️ **Clean Architecture**: Modular structure with reusable components and optimized asset handling for fast performance.

## Technologies Used

- **Next.js + React** – Component-driven frontend
- **Tailwind CSS** – Utility-first responsive styling
- **Firebase Auth** – Secure login and user management
- **Gemini AI API** – Smart and contextual recommendation engine
- **React Router** – Navigation and protected route management
- **Webpack + Pages.dev** – For blazing fast dev and deployment

## Challenges and Learnings

Working with Gemini AI APIs required careful prompt structuring and async handling to deliver accurate, context-aware suggestions. I also learned to balance route protection with user experience, ensuring secure yet seamless navigation.

## Outcome

**CinemaFlixGemini** reflects my capability to combine **modern UI/UX**, **AI integration**, and **secure infrastructure** into a rich streaming platform. It's a production-ready showcase for real-world application of AI in entertainment and frontend security patterns.

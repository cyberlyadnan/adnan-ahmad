## Overview

**SellGoLive** is a next-generation **live-commerce mobile application** designed to bring interactive shopping to life.  
The platform enables sellers to host live product showcases while viewers engage through **real-time chat, bidding, and instant purchase flows**.  
Built to support thousands of concurrent viewers using ultra-low-latency streaming technology.

This project demonstrates expertise in **mobile app development, real-time systems, and scalable cloud-backed architecture.**

---

## Key Features

- 🎥 **Live Streaming with Amazon IVS**  
  Ultra-low latency video streams for smooth live selling experiences.

- 💬 **Real-Time Chat**  
  Enables viewers to interact during live shows using Firebase real-time DB.

- 🔨 **Live Bidding System**  
  Users can place bids instantly on products featured during the stream.

- 🛒 **Product & Seller Dashboard**  
  Sellers manage products, pricing, streams, and bids from a dedicated panel.

- 🔔 **Push Notifications**  
  Alerts for upcoming live sessions, bids, and offers.

- 📱 **Cross-Platform UI**  
  Clean, modern React Native UI for smooth performance on all screen sizes.

## Technologies Used

- **Firebase Realtime Database**
- **Firebase Cloud Functions**

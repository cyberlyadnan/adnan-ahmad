## Overview

**The Heritage Global** is a professional portfolio website built for a multi-operational company based in Saharanpur, Uttar Pradesh, specializing in **manufacturing**, **retail**, and **exports**. The website provides a visually elegant and informative overview of the brand, its values, and its product portfolio.

As the developer, I focused on performance, accessibility, and SEO while crafting a clean and modern UI using **Next.js** and **TailwindCSS**.

## Key Features

- 💼 **Business Overview**: Communicates company vision, mission, and operational strengths clearly and concisely.
- 📦 **Product Showcases**: Displays a categorized list of export products, furniture, and handicrafts using grid-based responsive components.
- 🧭 **Navigation & Contact**: Intuitive menu structure and a detailed contact form for client inquiries.
- 🔍 **SEO Optimized**: Implemented meta tags, structured data, Open Graph tags, and sitemap generation for better visibility on Google.
- 🌐 **Fully Responsive**: Perfectly adapts across devices—from widescreen monitors to mobile phones.

## Technologies Used

- **Next.js 14**: Used for static site generation, routing, and performance.
- **TailwindCSS**: Enabled rapid styling with a responsive utility-first design.
- **Vercel**: For fast and secure deployment with custom domain configuration.
- **TypeScript**: Ensured type safety (optional), clean architecture, and better DX.
- **SEO & Performance Tools**: Integrated lighthouse checks, image optimization, Open Graph, and robots.txt.

## Challenges and Learnings

The key challenge was creating a visually rich site that loads fast without compromising on brand aesthetics. I learned to balance **design elegance** with **core web vitals** by lazy-loading images, optimizing fonts, and limiting heavy assets.

## Outcome

The final website gave Heritage Global a **professional online presence** that aligns with its global branding. It supports client trust, enhances discoverability, and creates opportunities for international inquiries.

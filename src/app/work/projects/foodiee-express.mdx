## Overview

**FoodieExpress** is a feature-rich food delivery web application inspired by Swiggy. It replicates the core functionalities of a food ordering system with live API integration, state management, and a beautiful responsive UI. The goal was to build a scalable, performant, and testable frontend application to demonstrate production-grade development practices using React.

## Key Features

- 🍽 **Swiggy-Like UI/UX**: Fully cloned Swiggy interface with navigation, menus, restaurant listings, and search.
- 🔄 **Live API Integration**: Connected to live APIs to fetch and render real-time data for restaurants and food items.
- 🧠 **Config-Driven UI**: Built UI components driven by dynamic configurations for easy scaling and customization.
- 🧭 **Dynamic Routing**: Implemented seamless navigation using **React Router Dom** for multi-page support.
- 🧰 **Custom Hooks**: Developed hooks for state logic reuse: `useState`, `useEffect`, `useSelector`, `useContext`.
- 🛠 **Global State Management**: Leveraged **Redux Toolkit** for managing global state across components.
- 📱 **Mobile-First Design**: Crafted responsive layouts using **Tailwind CSS** for seamless experience across devices.
- ✅ **Testing Suite**: Integrated **Jest** and **React Testing Library** for unit and integration testing of components.

## Technologies Used

- **React.js** – Frontend framework for building UI
- **React Router Dom** – Client-side routing
- **React Redux** – State management with Redux Toolkit
- **Tailwind CSS** – Utility-first CSS framework
- **Parcel** – Blazing-fast zero-config bundler
- **Jest** & **React Testing Library** – For frontend testing
- **Custom Hooks** – For encapsulating and reusing logic
- **Live APIs** – To simulate real-world data flow

## Outcome

This project deepened my understanding of **React architecture**, **state management patterns**, and **API integration strategies**. It also taught me the value of writing maintainable code using custom hooks and testing for component reliability. The responsive design ensures a seamless experience across all devices, and the live data integration adds real-time value to the app.

## Overview

**BazaarWala** is a powerful multi-vendor e-commerce platform designed to support small and growing sellers.  
The system allows vendors to create accounts, upload products, manage inventory, accept payments, and track orders — all within a scalable MERN architecture.

This project demonstrates experience in **marketplace development**, **payment systems**, and **secure multi-tenant design.**

---

## Key Features

- 🛍️ **Vendor Onboarding & Dashboard**  
  Sellers can register, manage products, and track orders.

- 🛒 **Product & Order Management**  
  Add, edit, delete products; real-time order updates.

- 💳 **Payment Gateway Integration**  
  Secure checkout system for buyers.

- 📦 **Multi-Vendor Architecture**  
  Each vendor manages their own store within the platform.

- 🧱 **Scalable MERN Stack Structure**  
  Designed for expansion with more sellers and high traffic.

## Overview

**Docs** is a modern, lightweight note-taking app inspired by Google Keep. It features a beautifully animated UI powered by **Framer Motion** and uses **localStorage** for offline data persistence. Designed for quick note capturing and playful interaction, each note acts like a draggable "bubble" on your screen.

## Key Features

- 📝 **Quick Note-Taking**: Users can instantly add, edit, and remove notes.
- 🪄 **Draggable Notes**: Notes can be freely dragged around the screen using **Framer Motion**, creating a screensaver-like experience.
- 💾 **Local Storage Persistence**: All notes are stored in the browser, allowing offline access with no backend required.
- 🧼 **Minimalist UI**: A clean, distraction-free interface built with **TailwindCSS** for fast load times and full responsiveness.
- 💻 **Open Source**: Freely available on GitHub for forking, customization, and extension.

## Technologies Used

- **React.js** – For building UI components and managing state
- **TailwindCSS** – For fast and responsive styling
- **Framer Motion** – For animations and draggable interactions
- **localStorage API** – For offline data persistence

## Challenges and Learnings

Creating a natural and fluid drag experience with **Framer Motion** required tuning interaction props like `dragElastic` and `layoutTransition`. I also focused on keeping the app fully accessible and mobile-optimized while using only the browser’s local storage.

## Outcome

**Docs** is more than a simple note app—it’s a delightful, interactive experience that showcases animation, local persistence, and design thinking. It demonstrates my capability to build engaging, offline-capable apps that feel alive and intuitive.

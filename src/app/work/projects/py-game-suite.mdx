## Overview

**PyGame Suite** is a desktop-based collection of fun and interactive games developed in Python using **Tkinter** for the graphical user interface. Designed with simplicity in mind, these games offer users a lightweight and nostalgic experience while showcasing the fundamentals of game development and UI logic in Python.

## Key Features

- 🎮 **Multiple Game Modules**: Includes mini-games like Tic Tac Toe, Snake, Memory Match, and more.
- 🖱️ **Tkinter GUI**: Intuitive and clean interface built entirely with Python’s built-in GUI toolkit.
- 🧩 **Logic-Oriented Gameplay**: Focused on turn-based, logic-driven games for all age groups.
- 🖥 **Cross-Platform Compatibility**: Runs seamlessly on Windows, macOS, and Linux without requiring heavy dependencies.
- 💡 **Educational Focus**: Demonstrates game loops, event handling, and GUI principles using core Python.

## Technologies Used

- **Python 3** – Core language for logic and functionality
- **Tkinter** – GUI library for Python-based desktop applications
- **Pillow (Optional)** – For handling game images and assets

## Outcome

This project served as an excellent foundation for mastering **GUI design**, **event-driven programming**, and **game logic** with Python. It not only deepened my understanding of object-oriented principles in Python but also enhanced my ability to deliver interactive user-facing applications.

## Overview

**Dreamline Wedding** needed a fast-performing landing funnel to convert social media traffic into high-intent travel inquiries.  
The goal was to eliminate heavy pages and create a **zero-friction, mobile-first** experience tailored for ads targeting users searching for destination weddings.

This project showcases skill in **conversion-focused UI**, **landing page optimization**, and **lightweight frontend engineering**.

---

## Key Features

- ⚡ **Super Fast Landing Page**  
  Pure HTML/CSS/JS for maximum speed & minimal loading time.

- 💌 **High-Conversion Inquiry Form**  
  Strategically placed CTA and optimized form fields for more leads.

- 🏖️ **Destination Highlights**  
  Clean visual layout showcasing travel packages & locations.

- 📱 **Mobile-First Design**  
  Fully optimized for mobile-based ad clicks.

- 🎯 **Ad Friendly Structure**  
  Designed to reduce bounce rate and increase inquiry submissions.

- **HTML / CSS / Bootstrap**

## Outcome

Dreamline Wedding saw improved lead quality and reduced bounce rates due to the funnel’s simplicity and speed.  
A perfect example of how **lightweight engineering + conversion strategy** outperform heavy websites for ad-driven traffic.

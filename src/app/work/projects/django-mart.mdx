## Overview

**DjangoMart** is a fully-functional eCommerce web application developed using Python and the Django framework. It features a smooth, user-friendly interface with powerful backend capabilities like secure authentication, product management, and payment integration.

## Key Features

- 🛍️ **Product & Inventory Management**: Admins can easily add, update, or delete products with stock tracking.
- 🔐 **Secure User Authentication**: User registration, login/logout, and profile management using Django’s built-in auth system.
- 🛒 **Shopping Cart System**: Add to cart, update quantities, and checkout experience handled with session-based cart logic.
- 💳 **Order Processing & History**: Full order lifecycle support with user-specific order tracking.
- 📊 **Admin Dashboard**: Comprehensive backend panel for order and inventory oversight.
- 🗂 **Category-Based Browsing**: Enables product filtering and easy navigation across categories.

## Technologies Used

- **Python** – Core programming language
- **Django** – MVC web framework for backend and routing
- **HTML/CSS & Bootstrap** – For frontend UI
- **SQLite3** – Lightweight database used for development
- **Django Templates** – Server-rendered pages for optimal performance

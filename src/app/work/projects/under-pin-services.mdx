## Overview

**Underpin Services** was a frontend assignment designed to evaluate skills in modern web development. The challenge was to build a pixel-perfect, SEO-optimized, and responsive web UI based on a provided Figma design. The project was completed within 2 days and deployed to Vercel, showcasing best practices in component architecture, accessibility, and performance optimization.

## Key Features

- **Responsive UI**: Fully responsive layout built for desktop, tablet, and mobile devices using Tailwind CSS.
- **SEO Optimization**:
  - Semantic HTML structure.
  - Open Graph and meta tag integration for social sharing and crawlability.
  - Sitemap and structured data readiness.
- **Performance Enhancements**:
  - Used `next/image` for optimized and lazy-loaded images.
  - Code splitting and dynamic imports via Next.js App Router.
  - Deployed on Vercel with edge caching and blazing-fast loading times.
- **Accessibility and Clean Code**:
  - Used semantic elements and ARIA roles.
  - Modular, reusable components with type-safe definitions (TypeScript-ready).

## Technologies Used

- **Next.js 14 (App Router)** – Full app routing, SSR-ready pages.
- **Tailwind CSS** – Utility-first styling for rapid development.
- **TypeScript** – Optional but structured the project to support it fully.
- **Vercel** – Seamless deployment and previewing.
- **Figma** – UI design reference used for pixel-perfect implementation.

## Challenges and Learnings

A key challenge was understanding and applying **SEO fundamentals** in a real-world build, especially around meta tags, Open Graph data, and responsive semantics. Learning how to implement `next/image` properly for performance without layout shifts was another great takeaway. The App Router’s layout and routing system was also put into practical use for the first time.

## Outcome

The completed assignment demonstrates a strong command of frontend engineering fundamentals—responsive layouting, clean architecture, SEO, and performance. The project stands as a fast-loading, SEO-friendly single-page UI that aligns with real-world expectations for modern startups and tech firms.
